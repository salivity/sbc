Designing Reliable Power-On-Reset for Multi-Core SBCs

Power-on-reset (POR) circuitry ensures that a multi-core embedded single-board computer (SBC) boots into a known, deterministic state every time power is applied. Designing a reliable POR circuit requires managing complex power supply sequencing, overcoming brownout vulnerabilities, ensuring clock stabilization, and synchronizing reset signals across multiple high-performance processor cores. This article outlines the key engineering strategies and architectural principles used to design robust POR systems for modern multi-core SBCs.

The Failure Modes of Simple RC Reset Circuits

In basic microcontrollers, an RC (resistor-capacitor) network is sometimes used to delay the reset release until the voltage rail rises. In high-performance, multi-core embedded systems, this approach fails due to several critical flaws:

  • Slow Slew Rates: A slow-rising voltage edge on a reset pin can cause internal logic gates to linger in an indeterminate linear region, leading to high shoot-through current and oscillation.
  • Sensitivity to Power Glitches: RC circuits cannot detect rapid brownout conditions or micro-interruptions on power rails, leaving the CPU running at sub-nominal voltages where register corruption occurs.
  • Lack of Multi-Rail Awareness: Multi-core systems feature separate voltage rails for CPU cores (often sub-1V), I/O (1.8V/3.3V), and DDR memory (1.1V–1.35V). An RC circuit cannot coordinate reset states across these independent rails.

Utilizing Dedicated Voltage Supervisors and PMICs

Reliable SBC designs utilize dedicated hardware supervisors or integrated Power Management Integrated Circuits (PMICs) to monitor power integrity.

  1. Threshold Monitoring: Voltage supervisors contain precision bandgap references and internal comparators to monitor each power rail. Reset remains asserted until all monitored rails exceed predefined threshold voltages (typically within 3% to 5% of their nominal values).
  2. Built-in Hysteresis: Supervisory ICs incorporate voltage hysteresis to prevent "reset chattering" or oscillation when the supply voltage hovers near the threshold during turn-on.
  3. Open-Drain Outputs with Pull-Ups: Reset outputs are typically configured as open-drain, allowing multiple supervisors to be wired together in a wire-OR configuration to hold the master reset low if any single power domain faults.

Power Sequencing and Reset Timing

Multi-core SoCs (System-on-Chips) mandate strict power-up sequencing to avoid latch-up conditions or excessive inrush currents. The I/O rails, core logic, and peripheral supplies must ramp in a specific order (e.g., I/O first, Core second, or vice-versa, depending on silicon specifications).

  • Power Good (PGOOD) Aggregation: Each voltage regulator generates a PGOOD signal once its output stabilizes. These signals are daisy-chained or aggregated via logic gates into the master reset controller.
  • Configurable Reset Delay (\(t_{RST}\)): Once all rails report healthy power, the reset circuit maintains the reset state for an additional delay period (typically 50 ms to 200 ms). This ensures that crystal oscillators and internal Phase-Locked Loops (PLLs) achieve stable phase-lock before the multi-core SoC executes its initial instruction fetch.

Orchestrating Multi-Core Reset Hierarchies

A multi-core processor does not treat all resets identically; modern designs use hierarchical reset trees.

  • Cold Reset vs. Warm Reset: A cold reset reinitializes all internal state machines, registers, debug units, and PLLs upon power application. A warm reset reinitializes processor cores without power-cycling high-speed memory interfaces, preserving debug information and reducing reboot latency.
  • Primary Core Bootstrapping: The POR circuit initially releases only the primary/boot core. The primary core initializes clocks, memory controllers, and security domains, subsequently releasing the secondary cores via software-accessible reset control registers within the SoC.
  • Board-Level Peripheral Synchronization: High-speed peripherals (e.g., PCIe switches, Ethernet PHYs, eMMC storage) must be held in reset until the host processor's I/O lines are configured to prevent bus contention and invalid state detection.

Robustness Against Brownouts and Transients

To ensure long-term reliability in harsh operating environments, engineers integrate supplementary protection mechanisms:

  • Fast-Response Undervoltage Lockout (UVLO): If a voltage dip lasts longer than a few microseconds, the supervisor must pull the reset line low before the core supply drops below the minimum operating threshold.
  • Manual Reset and Watchdog Integration: Many supervisors incorporate an active-low manual reset input (with integrated debouncing) and a watchdog timer input, providing a fail-safe fallback to trigger a full hardware POR if firmware enters an unrecoverable hang.
  • Physical Layout Isolation: Reset traces are routed away from high-speed switching nodes (e.g., DC-DC inductors, high-speed clocks) and shielded with ground planes to prevent capacitive coupling and spurious reset pulses.
