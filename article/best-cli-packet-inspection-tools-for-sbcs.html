Best CLI Packet Inspection Tools for SBCs

Headless single-board computers (SBCs) such as the Raspberry Pi, BeagleBone, and Orange Pi are frequently deployed as compact network probes, firewalls, and diagnostic devices. Because these systems run without a graphical desktop environment and have limited CPU and RAM resources, network analysis must be performed efficiently via the terminal. This article examines the best command-line interface (CLI) software tools available for capturing, filtering, and inspecting network packets on headless single-board computers.

1. tcpdump

tcpdump is the standard tool for command-line packet analysis across Unix-like operating systems. It is extremely lightweight, consumes minimal system memory, and is often pre-installed or available in standard package repositories.

  • Key Features: Uses libpcap to capture raw packets; supports complex Berkeley Packet Filters (BPF) to isolate specific traffic by IP, port, or protocol; outputs captures directly to standard .pcap files for offline analysis.
  • Best Used For: Low-overhead live captures and initial troubleshooting on hardware with strict memory and CPU constraints.
  • Basic Command: 
    sudo tcpdump -i eth0 -nn -c 100 port 80

2. TShark

TShark is the terminal-based counterpart to Wireshark. It utilizes the same packet dissection engine as the GUI version, allowing deep inspection of hundreds of network protocols directly from the shell.

  • Key Features: Advanced protocol dissection; powerful display filters matching Wireshark syntax; ability to export dissected fields directly to text, CSV, or JSON formats.
  • Best Used For: Complex protocol decoding (e.g., inspecting TLS handshakes, DNS queries, or HTTP headers) directly from the command line.
  • Basic Command: 
    sudo tshark -i eth0 -Y "http.request.method == GET" -T fields -e http.host -e http.request.uri

3. Termshark

Termshark provides a terminal user interface (TUI) inspired by the layout of Wireshark. Built on top of TShark using Go, it offers an interactive three-pane interface (packet list, packet details, and packet hex/bytes) inside an SSH session.

  • Key Features: Keyboard and mouse navigation inside the terminal; real-time filtering; visual inspection of protocol layers without needing an X11 server or exporting .pcap files to a local machine.
  • Best Used For: Interactive packet analysis over SSH when a graphical environment is not available.
  • Basic Command: 
    termshark -i eth0

4. ngrep (Network Grep)

ngrep combines the packet-matching capabilities of BPF filters with the text-matching capabilities of GNU grep. It allows users to search for specific strings or regular expressions across unencrypted payload data.

  • Key Features: Real-time payload matching; intuitive syntax for filtering application-layer protocols such as plain HTTP, SIP, or SMTP; low resource overhead.
  • Best Used For: Quickly searching for specific text patterns, authentication strings, or error codes passing through network interfaces.
  • Basic Command: 
    sudo ngrep -q -W byline "USER|PASS" port 21

5. netsniff-ng

netsniff-ng is a high-performance network sniffer and toolkit designed for Linux. It utilizes a zero-copy packet capture mechanism via memory-mapped rings (mmap(2)), significantly reducing CPU overhead and kernel-to-userspace context switches.

  • Key Features: Minimal packet drop rates under heavy network load; native support for BPF filters; optimized for high-throughput packet captures.
  • Best Used For: High-speed packet capture on resource-limited SBCs monitoring saturated 1Gbps interfaces.
  • Basic Command: 
    sudo netsniff-ng --in eth0 --out capture.pcap

Tool Selection Guide

  • For minimal resource footprint: Use tcpdump.
  • For detailed protocol dissection: Use TShark.
  • For an interactive, visual terminal workflow: Use Termshark.
  • For payload text searching: Use ngrep.
  • For high-throughput capture with zero packet loss: Use netsniff-ng.
