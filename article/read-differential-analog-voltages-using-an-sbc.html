Read Differential Analog Voltages Using an SBC

Single-board computers (SBCs) like the Raspberry Pi operate purely in the digital domain and lack built-in analog-to-digital converters (ADCs). To read differential analog voltage signals—which measure the voltage difference between two distinct points rather than referencing a common ground—developers must interface an external ADC breakout board with the SBC. This article explains the hardware setup, communication protocols, and software implementation required to capture accurate differential analog signals on an SBC.

1. Select a Differential ADC Breakout Board

To read differential signals, select an ADC breakout board with native differential input support and a compatible communication bus (typically I2C or SPI).

  • Texas Instruments ADS1115: A popular 16-bit, 4-channel ADC breakout that uses I2C. It provides two differential channels, a programmable gain amplifier (PGA), and configurable data rates up to 860 samples per second.
  • Microchip MCP3008 / MCP3208: 10-bit and 12-bit SPI ADCs offering pseudo-differential and differential measurement modes across multiple channels.

For high-resolution and low-noise applications, the ADS1115 is widely considered the industry standard for SBC integration.

2. Wire the Hardware

Connect the ADC breakout board to the SBC's GPIO header and attach your analog signal sources to the designated input pins.

SBC to ADC Connections (I2C Example)

  • VDD / VCC: Connect to the SBC's 3.3V power output.
  • GND: Connect to an SBC Ground pin.
  • SCL: Connect to the SBC I2C Clock pin (e.g., GPIO 3 on Raspberry Pi).
  • SDA: Connect to the SBC I2C Data pin (e.g., GPIO 2 on Raspberry Pi).
  • ADDR: Connect to GND to set the default I2C address (0x48).

Signal Source Connections

  • Positive Lead (Signal +): Connect to Channel 0 (A0).
  • Negative Lead (Signal -): Connect to Channel 1 (A1).
  • Common Ground Reference: Ensure the signal source's ground is referenced within the common-mode voltage limits defined by the ADC's datasheet.

3. Enable Communication Interfaces on the SBC

Before reading data, enable the hardware interface on your operating system. For Raspberry Pi OS:

  1. Open the terminal and run sudo raspi-config.
  2. Navigate to Interface Options > I2C and select Enable.
  3. Reboot the SBC.
  4. Verify detection by running i2cdetect -y 1. The device should appear at address 0x48.

4. Read Data with Software

Using Python, developers can read differential channels with libraries such as Adafruit CircuitPython.

Install the required packages:

pip install adafruit-circuitpython-ads1x15

Execute the following script to read the differential voltage between pins A0 and A1:

import time
import board
import busio
from adafruit_ads1x15.ads1115 import ADS1115
from adafruit_ads1x15.analog_in import AnalogIn

# Initialize I2C interface
i2c = busio.I2C(board.SCL, board.SDA)

# Initialize ADC
ads = ADS1115(i2c)

# Configure gain (1 = +/-4.096V range, 2/3 = +/-6.144V range)
ads.gain = 1

# Create a differential channel between Pin 0 and Pin 1
differential_channel = AnalogIn(ads, ADS1115.P0, ADS1115.P1)

print("Reading differential voltage. Press Ctrl+C to stop.")

try:
    while True:
        raw_value = differential_channel.value
        voltage = differential_channel.voltage
        print(f"Raw ADC Value: {raw_value} | Differential Voltage: {voltage:.4f} V")
        time.sleep(0.5)
except KeyboardInterrupt:
    print("\nReading stopped by user.")

5. Key Considerations for Differential Measurement

  • Programmable Gain Amplifier (PGA): Adjust the ADC gain setting to match the maximum expected differential voltage. Matching the range maximizes the measurement resolution.
  • Common-Mode Voltage Limits: Differential inputs cannot float arbitrarily high; both input pins must remain between the ADC's ground and supply voltage (typically GND - 0.3V to VDD + 0.3V).
  • Noise Rejection: Differential signaling inherently rejects common-mode noise. Use twisted-pair wiring for the analog signal leads to minimize electromagnetic interference (EMI).
