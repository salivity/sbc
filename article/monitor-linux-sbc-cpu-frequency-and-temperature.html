Monitor Linux SBC CPU Frequency and Temperature

Single Board Computers (SBCs) running Linux often operate under demanding workloads within compact, passively cooled enclosures. Monitoring CPU frequency and core temperatures in real time is essential to prevent thermal throttling and ensure system stability. This article outlines the best command-line tools, board-specific utilities, and real-time terminal dashboards designed for tracking SBC performance.

1. s-tui (Stress Terminal UI)

s-tui is a terminal-based, graphical monitor built specifically for tracking CPU metrics. It displays real-time graphs for CPU frequency, temperature, utilization, and power consumption simultaneously without requiring an X-server or desktop environment.

  • Installation: 
    sudo apt install s-tui
  • Usage: Run s-tui directly in your terminal. It also features a built-in stress-testing utility to monitor how hardware behaves under maximum load.

2. Built-in Linux Sysfs (/sys Virtual Filesystem)

Linux exposes raw hardware sensor readings directly through the sysfs interface. This method requires no external package installations and uses minimal system resources.

  • Check Temperature: 
    cat /sys/class/thermal/thermal_zone0/temp
    (Divide the output value by 1000 to get degrees Celsius.)
  • Check Real-Time Frequency: 
    cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_cur_freq
    (Divide the output value by 1000 to get the frequency in MHz.)
  • Continuous Monitoring: Pair with the watch command to refresh every second: 
    watch -n 1 "cat /sys/class/thermal/thermal_zone0/temp && cat /sys/devices/system/cpu/cpu*/cpufreq/scaling_cur_freq"

3. btop / htop

Modern system monitors provide real-time hardware status alongside process management.

  • btop: Provides an interactive dashboard showing core-by-core CPU frequencies, temperatures (if supported by the kernel), memory usage, and running processes. 
    sudo apt install btop
btop
  • htop: While primarily a process viewer, htop can be configured via Setup (F2) > Display options to show individual core frequencies and system temperatures directly in the header meters.

4. cpufrequtils

The cpufrequtils package provides dedicated tools to inspect CPU governors, maximum and minimum supported frequencies, and current operational clock speeds.

  • Installation: 
    sudo apt install cpufrequtils
  • Usage: 
    cpufreq-info
    To watch changes live: 
    watch -n 1 cpufreq-info

5. Board-Specific Utilities

Raspberry Pi (vcgencmd)

For Raspberry Pi OS, the native vcgencmd tool directly queries the VideoCore firmware for accurate temperature and clock data:

  • Temperature: vcgencmd measure_temp
  • Clock Frequency: vcgencmd measure_clock arm

Armbian-Based SBCs (armbianmonitor)

Armbian includes a custom monitoring suite tailored for Orange Pi, Banana Pi, Odroid, and other supported boards:

  • Real-time Stream: 
    sudo armbianmonitor -m
    This command outputs a live, streaming table showing CPU frequency, temperature, governor status, and system load per second.
