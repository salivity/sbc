Calibrate Analog Inputs on Single Board Computers

Calibrating analog inputs on a multi-purpose single board computer (SBC) involves measuring known precision reference voltages, calculating hardware-induced offset and gain errors, and applying a mathematical correction in software. This process compensates for analog-to-digital converter (ADC) non-linearities, reference voltage tolerances, and temperature drift, ensuring that raw digital readings accurately represent real-world physical voltages.

Understanding ADC Inaccuracies

Microcontrollers and SBCs typically contain internal ADCs that convert voltage into discrete numerical values (counts). These converters are prone to several types of hardware errors:

  • Offset Error: A constant shift where a \(0\text{V}\) input produces a non-zero digital reading (or reaches zero prematurely).
  • Gain Error: A deviation in the slope of the transfer function, causing errors that scale proportionally with input voltage.
  • Non-Linearity (INL/DNL): Imperfections where the ADC response curves rather than remaining strictly linear.

Required Hardware Setup

To perform an accurate calibration, an engineer needs:

  1. A Precision Voltage Reference: A calibrated DC power supply, a dedicated precision voltage reference IC (such as a 2.048V or 3.3V reference with \(\le 0.1\%\) tolerance), or a high-accuracy digital multimeter (DMM).
  2. Common Grounding: Connect the reference ground directly to the SBC's analog ground (AGND) to eliminate ground loop offsets.
  3. Stable Power Supply: Ensure the SBC is powered by a stable source, as ripple on the internal supply rail can skew ADC conversion if used as the ADC's reference.

Two-Point Linear Calibration Procedure

For most linear ADCs, a two-point calibration effectively eliminates both offset and gain errors.

1. Measure the Low-Point Reference

Apply a stable voltage near the lower limit of the ADC range (for example, 10% of full scale) and record the measured raw ADC value.

  • \(V_{1}\) = Applied low voltage (verified via DMM)
  • \(ADC_{1}\) = Average raw digital reading over multiple samples (e.g., 64–100 samples to average out noise)

2. Measure the High-Point Reference

Apply a stable voltage near the upper limit of the ADC range (for example, 90% of full scale) and record the measured raw ADC value.

  • \(V_{2}\) = Applied high voltage (verified via DMM)
  • \(ADC_{2}\) = Average raw digital reading

3. Calculate Gain and Offset Correction Factors

Using the linear equation \(V = m \cdot ADC + c\):

  • Slope (\(m\)): \[m = \frac{V_{2} - V_{1}}{ADC_{2} - ADC_{1}}\]
  • Offset (\(c\)): \[c = V_{1} - (m \cdot ADC_{1})\]

Multi-Point (Polynomial) Calibration for Non-Linear ADCs

Some SBCs and microcontrollers exhibit significant non-linear behavior, particularly at the extreme ends of their measurement range. In these cases:

  1. Apply 5 to 10 known voltage steps across the full operating range.
  2. Record the averaged ADC values at each step.
  3. Perform a polynomial regression (typically 2nd or 3rd order) or generate a look-up table (LUT) with linear interpolation between points.

Implementing Calibration in Software

Once the calibration parameters (\(m\) and \(c\), or polynomial coefficients) are determined:

  1. Store Calibration Constants: Save the parameters in non-volatile memory (EEPROM, Flash, or a configuration file on the SBC's filesystem) so they persist across reboots.
  2. Runtime Application: Apply the formula to incoming raw readings before passing data to applications: 
    float get_calibrated_voltage(int raw_adc) {
    return (slope * raw_adc) + offset;
}
  3. Oversampling: Implement digital oversampling and averaging in the driver layer to reduce random thermal noise and improve measurement stability.
